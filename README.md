หลักการทำงาน 
------------
GitHub repository = ฐานความรู้ (เก็บไฟล์ .txt ของกฎหมาย/ระเบียบ) — อัปโหลดไฟล์ใหม่ผ่านหน้าเว็บ GitHub ได้เลย (ลากไฟล์วาง ไม่ต้องเขียนโค้ด)
GitHub Pages = หน้าเว็บสาธารณะฟรี ที่จะดึงไฟล์จาก repo มาค้นหาในเบราว์เซอร์ของผู้ใช้เอง (ไม่มีเซิร์ฟเวอร์กลาง ไม่มีค่าใช้จ่าย)

ข้อจำกัดที่ต้องรู้:
------------
repo ต้องเป็น public (เนื้อหากฎหมายเป็นข้อมูลสาธารณะอยู่แล้วไม่มีปัญหาความเป็นส่วนตัว) เพราะหน้าเว็บต้องดึงไฟล์แบบไม่ล็อกอิน
ไฟล์ความรู้ควรเป็น .txt หรือ .md (ไม่ใช่ PDF/Word) เพราะเบราว์เซอร์อ่านข้อความล้วนได้ตรงที่สุด — ถ้ามีไฟล์ PDF ต้อง copy เนื้อหาไปวางเป็นไฟล์ข้อความก่อน
GitHub API ให้เรียกฟรีได้จำกัดประมาณ 60 ครั้ง/ชั่วโมง/ผู้เข้าชม 1 คน ซึ่งเพียงพอสำหรับการค้นหาปกติ

วิธีติดตั้ง
---------
ไปที่ github.com → สร้างบัญชี (ถ้ายังไม่มี ฟรี) → New repository → ตั้งชื่อ (เช่น coop-labor-law-search) → เลือก Public → Create
ในหน้า repo → Add file → Create new file → ตั้งชื่อ index.html → วางเนื้อหาจากไฟล์ index.html ที่ให้ไป
แก้ 2 บรรทัดบนสุดของ <script> ในไฟล์ ให้ตรงกับ repo ของคุณ:
   const GITHUB_OWNER = 'ชื่อบัญชี GitHub ของคุณ';
   const GITHUB_REPO = 'coop-labor-law-search';
สร้างโฟลเดอร์ knowledge ในหน้า repo → Add file → Upload files → ลากไฟล์ .txt เนื้อหากฎหมาย (ดูตัวอย่างรูปแบบจากไฟล์ที่ให้ไป) วางเข้าไป → Commit
ไปที่ Settings → Pages → Source เลือก branch main → Save
รอ 1-2 นาที จะได้ลิงก์ประมาณ https://ชื่อบัญชี.github.io/coop-labor-law-search/ แชร์ลิงก์นี้ให้ใครก็เข้าใช้ได้เลย ฟรีตลอดไป ไม่ต้องมีเซิร์ฟเวอร์
การเพิ่มความรู้ใหม่ในอนาคต: แค่เข้า repo → เปิดโฟลเดอร์ knowledge → Add file → Upload files → เพิ่มไฟล์ .txt ใหม่เข้าไป หน้าเว็บจะดึงมาแสดงให้อัตโนมัติในการค้นหาครั้งถัดไป ไม่ต้องแก้โค้ดใด ๆ
